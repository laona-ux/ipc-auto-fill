# 工控机自动填入数值工具（ipc-auto-fill）

笔记本读 Excel/CSV 表格，把数值一条条自动「点进」工控机的小屏幕软件里。
每次填完一条，等你人工确认无误后才填下一条（也支持校准模式自动试点）。

---

## 1. 方案原理

```
┌─────────────┐   USB线    ┌───────────────────────────────┐   USB口   ┌──────────────────┐
│ Windows 笔记本 │ ─────────▶ │ 树莓派 Pico（模拟成USB键盘+鼠标） │ ─────────▶ │ 工控机（只有USB-A口）│
│  run.py 读表格  │  (串口指令) │  插在工控机唯一的USB-A口上       │  (标准HID)  │  小屏幕上的软件     │
└─────────────┘            └───────────────────────────────┘           └──────────────────┘
```

- 你的 Windows 笔记本负责：读表格、计算坐标、发指令、等人工确认。
- 树莓派 Pico 负责：把自己伪装成工控机眼里的「USB 键盘 + USB 鼠标」，执行移动光标、点击、输入。
- 笔记本和 Pico 之间用一根 **USB 转 TTL 串口线** 通信（Pico 的 GPIO 串口接 CH340，CH340 插笔记本）。
- **为什么必须买 Pico 而不是直接让笔记本当键盘？** Windows 笔记本的 USB 口只能做「主机」，无法反过来被工控机识别成输入设备，所以中间必须有一个能模拟 HID 的小硬件。Pico 是最便宜可靠的方案（约 ¥15）。

### 「手动定位数值」怎么落地的
工控机屏幕小，软件窗口位置固定，输入框的坐标（x, y 像素）基本固定。
- 你把每个输入框的坐标填进 `host/config.json`（第一次要用校准模式试出来，见第 8 节）。
- 脚本让 Pico 用**相对移动**把光标精确移动到坐标再点击（Pico 自己记着光标上一次的位置，从上次位置算差值，所以不需要知道屏幕分辨率）。
- 每次运行前：人工把工控机上的鼠标光标移到**屏幕左上角**按回车，脚本就发 `home` 命令让 Pico 把坐标原点对准左上角，之后全部自动。**注意：开始后不要再手动动工控机的鼠标/触摸屏**，否则坐标会偏移。

> 换更省事的思路：如果工控机软件能用 Tab 键在输入框之间跳转，可以把 `config.json` 里的目标模式设成 `keyboard`，脚本只用键盘导航和输入，完全不用鼠标定位。两种模式都支持，见第 7 节。

## 2. 需要购买哪些设备（只买这几样，约 ¥20～¥40）

| 设备 | 作用 | 建议 | 参考价 |
|---|---|---|---|
| 树莓派 Pico（RP2040） | 模拟 USB 键盘+鼠标 | 淘宝搜「树莓派 Pico RP2040」，原版或兼容版都行，**不要买 Pico 2/RP2350**（本固件按 RP2040 调好） | ¥10～15 |
| USB 转 TTL 串口模块（CH340 或 CP2102） | 笔记本 ↔ Pico 通信 | 买带 **3.3V 电平/供电跳线** 的型号（CP2102 基本都是 3.3V） | ¥3～8 |
| Micro-USB 数据线 1 根 | Pico 的 USB 口连工控机（注意要**能传数据**的线，不是充电线） | 原版 Pico 是 Micro-USB 口；USB-A 公头插工控机 | ¥5～10 |
| 杜邦线（母对母）4 根 | 接 Pico GPIO 和 CH340 | 任意 | ¥1～2 |

不需要再买别的。笔记本、Excel、USB 线你都有。

### 备选方案对比（一般不推荐）
- **树莓派 Zero 2W（约 ¥120）**：USB OTG 直接模拟 HID，还带网卡/蓝牙，可以不买 CH340。但贵、配置复杂。
- **成品「USB 键鼠模拟器 / BadUSB」**：淘宝有，但编程不透明、坐标控制能力差，不推荐自己开发用。
- **远程控制软件（VNC/ToDesk）**：前提是工控机能联网或接网线，且允许装软件。你的场景只有 USB 口，所以走硬件注入。

## 3. 接线

CH340 模块（插笔记本）与 Pico（插工控机）之间，用杜邦线接：

| Pico 引脚 | CH340 模块 |
|---|---|
| `GP0`（UART0 TX） | `RXD` |
| `GP1`（UART0 RX） | `TXD` |
| `GND`（任意一个 GND） | `GND` |

注意：
- **不要**把 CH340 的 5V/VCC 输出接到 Pico 的 GPIO 或 3V3 脚（电平是 3.3V，防止烧板）。CH340 模块自己用 USB 供电即可；如果模块必须跳线选择电平，拨到 **3.3V**。
- TX/RX 交叉接（A 的 TX 接 B 的 RX）。
- Pico 的 USB（Micro-USB）插工控机的 USB-A 口。

```text
  工控机 USB-A ──Micro-USB线──▶ [Pico]
                                 │ GP0──RXD
                                 │ GP1──TXD        [CH340]──USB──▶ 笔记本
                                 │ GND──GND
```

## 4. 安装步骤

### 4.1 给 Pico 烧 CircuitPython 固件（一次性）
1. 按住 Pico 板上的 `BOOTSEL` 按钮，同时用 Micro-USB 线插到电脑，松手。电脑会多出一个 U 盘（RPI-RP2）。
2. 到 https://circuitpython.org/board/raspberry_pi_pico/ 下载 **CircuitPython 8.x** 的 `.uf2` 文件（注意别下 9.x 或 Pico 2 的文件）。
3. 把 `.uf2` 拖进那个 U 盘，Pico 会自动重启，变成一个叫 `CIRCUITPY` 的 U 盘。
4. 下载 **Adafruit CircuitPython Bundle**（与 CircuitPython 版本对应的 8.x 版）：https://github.com/adafruit/Adafruit_CircuitPython_Bundle/releases
5. 解压后，把 `lib/adafruit_hid/` 整个文件夹复制到 `CIRCUITPY` 盘的 `lib/` 里。
6. 把本项目的 `pico/boot.py` 和 `pico/code.py` 复制到 `CIRCUITPY` 盘根目录（覆盖同名文件）。

### 4.2 笔记本装环境（一次性）
1. 装 Python 3.10+：https://www.python.org/downloads/ （安装时勾选 **Add Python to PATH**）。
2. 打开 PowerShell 或 CMD，执行：
   ```powershell
   pip install pyserial openpyxl
   ```
3. 找到笔记本上 CH340 插上后出现的串口号：右键「此电脑 → 管理 → 设备管理器 → 端口(COM 和 LPT)」，记下如 `COM3` 的名字（插拔再看一眼确认是哪个）。

### 4.3 工控机侧
**工控机上不用装任何东西、不用改任何设置。** 把 Pico 插进它的 USB-A 口，它看到的就是一个「USB 输入设备」（键盘+鼠标）。如果工控机的文件管理器里多出一个 `CIRCUITPY` 盘符，那是 Pico 的文件系统，忽略即可，不影响使用。

## 5. 表格格式（Excel 或 CSV）

支持几乎任意结构：`.xlsx / .xlsm / .xls / .csv`，自动按扩展名区分。列名随意，例如：`序号, 温度, 压力, 转速`。

- 默认**第一行是表头**；若表头不在第一行，把 `header_row` 设为表头所在行号（0-based）。
- 若表格**没有表头**，把 `has_header` 设为 `false`，脚本自动按 `col1/col2…` 生成列名，
  此时 `header_row` 表示第一条数据所在行号（可用来跳过前面的标题行），并用 `col` 填列名或 0-based 列序号。
- 每一行是一条记录，脚本把这一行的数值逐项填到工控机上。
- 数值支持数字、小数、正负号（如 `123.45`、`-12.5`、`0.8`）和普通英文/数字/符号。**不支持中文**（USB 键盘协议只能发英文键码）。

示例 `values.xlsx`：

| 序号 | 温度 | 压力 | 转速 |
|---|---|---|---|
| 1 | 25.5 | 101.3 | 1500 |
| 2 | 26.0 | 102.1 | 1600 |

> 读取 `.xls` 需要 `pip install xlrd`；`.xlsx/.xlsm` 需要 `pip install openpyxl`；`.csv` 无需额外库。

## 6. 配置文件 `host/config.json`

> 这是一个「步骤流程」配置。核心是 `steps`：**对表格的每一行数据，按顺序把这些步骤执行一遍**。
> 所以你可以做到：点击进入某个界面 → 填入数值 → 返回主界面 → 再进入另一个界面 → 再点……这正是工控机上常见的「翻页录入」。
> 旧版「targets」配置仍完全兼容：没有 `steps` 时会自动按老方式展开。

```jsonc
{
  "com_port": "COM3",          // 笔记本上 CH340 的串口号（设备管理器里看）
  "baudrate": 115200,          // 波特率，固件和脚本默认一致，不用改
  "data_file": "values.xlsx",  // Excel/CSV 文件路径（相对 host/ 目录或绝对路径）
  "sheet": "Sheet1",           // 工作表名，留空取第一个
  "header_row": 0,             // 表头所在行号（0-based）；缺省 0
  "has_header": true,          // false=没有表头，自动按 col1/col2… 生成列名（此时 header_row 指首条数据行）
  "row_start": 1,              // 只填从第几条（数据行，1-based）开始
  "row_end": 0,                // 填到第几条为止；0=到末尾。配合上一条可只填表格的一部分行
  "confirm": "enter",          // "enter"=每填完一行，人工看完工控机屏幕后点确认再填下一行；"none"=不停
  "start_home": true,          // true=每次运行前要求把工控机鼠标移到屏幕左上角，自动校准原点
  "step_delay_ms": 300,        // 默认动作间停顿（毫秒），工控机软件反应慢就调大
  "steps": [                   // ───────── 步骤流程 ─────────
    { "type": "button", "name": "进入压力界面" },          // 执行自定义按钮的步骤
    { "type": "input", "col": "稳定压力(MPa)", "round": 2, // 填这一行「稳定压力(MPa)」列的值，保留2位
      "pre_keys": ["ctrl+a"], "enter": true,
      "suffix": " MPa", "default": "0.0", "name": "填入压力" },  // 后缀单位 + 空值兜底
    { "type": "button", "name": "返回主界面" },            // 例如：按 Esc 返回
    { "type": "button", "name": "进入注浆界面" },
    { "type": "input", "col": 2, "round": 2,               // col 也可以是列序号（0-based，第3列）
      "pre_keys": ["ctrl+a"], "enter": true, "name": "填入注浆量" },
    { "type": "button", "name": "返回主界面" },
    { "type": "confirm", "name": "本行填完，核对无误后点『已确认』" }
  ],
  "buttons": {                 // ───────── 自定义按钮（可复用/快捷执行）─────────
    "进入压力界面": [ { "type": "click", "x": 120, "y": 160, "name": "点开压力录入" } ],
    "进入注浆界面": [ { "type": "click", "x": 120, "y": 224, "name": "点开注浆录入" } ],
    "返回主界面":   [ { "type": "key", "key": "escape", "name": "按 Esc 返回" } ]
  }
}
```

### 步骤类型（steps 里的每一项）

| `type` | 作用 | 主要字段 |
|---|---|---|
| `click` | 移动到 (x,y) 并单击（进入界面/点按钮） | `x`,`y` |
| `dblclick` | 移动到 (x,y) 并双击 | `x`,`y` |
| `press_at` | 移动到 (x,y) 按住左键 `ms` 毫秒（长按） | `x`,`y`,`ms` |
| `move` | 只移动光标到 (x,y)，不点击 | `x`,`y` |
| `scroll` | 滚动滚轮 | `delta`（>0 上滚，<0 下滚） |
| `key` | 按一个键 | `key`（enter/tab/esc/f5/ctrl+a …），`times`（重复次数） |
| `input` | 填入一个数值 | `col`（列名或0-based列序号）/`value`（固定值），`prefix`/`suffix`（前后缀），`default`（空值兜底），`pre_keys`（先清空），`round`（小数位），`enter`（回车） |
| `sleep` | 等待 `ms` 毫秒 | `ms` |
| `home` | 让光标回屏幕左上角并重设原点 | — |
| `confirm` | 暂停，等人点『已确认』 | `name`（提示语） |
| `button` | 引用自定义按钮，执行时展开 | `name`（按钮名） |

- 每个步骤可选 `name`（说明文字）和 `delay_ms`（动作后额外停顿，默认用 `step_delay_ms`）。
- `input` 步骤：填了 `col` 就从表格那一行的该列取值；没填 `col` 就用 `value` 的固定值。
- 新坐标/按钮的坐标用第 8 节的校准模式试出来。**注意：校准坐标会把流程里的按钮内联展开**，之后流程变成明确的 click 步骤（按钮库本身不变，仍可在下方快捷区一键执行）。

## 7. 使用流程

### 7.1 图形界面操作（推荐）

除命令行外，还提供可视化界面（Tkinter，Python 自带，不需要再装别的库）。日常使用推荐用它：

```powershell
cd host
python gui.py
```

界面操作概览：

1. **连接**：顶部选串口（点「刷新」列出 COM 口）、波特率，点「测试 Pico」确认在线；选数据文件（自动列出**工作表**下拉，`.xls`/`.xlsx`/`.csv` 都行）、设 `表头行` 和 `有表头`，点「载入表格」校验表格并把表头填进「表格列」下拉。
2. **行列与步骤（三步走）**：载入表格后——
   - **选行**：在上方「填充行」里填「从第 _ 行 到第 _ 行（0=全部）」，只填范围内的数据行（配合断点续传：中断后从范围与断点的交集继续）。
   - **选列**：在「选择要填入的表格列」列表里按住 Ctrl/Shift **多选要填的列**。
   - **生成步骤**：点「▶ 将选中列生成填入步骤」，每一列自动生成一个带「先 Ctrl+A 清空 + 输入后回车」的 `输入数值` 步骤，追加到当前流程末尾；再在步骤编辑器里前后加「点击/按键/自定义按钮」就有完整流水线了。
3. **步骤流程（核心）**：中间列表的**每一行是一个步骤**，对范围内每一行表格数据按顺序执行一遍。点一行，右侧表单显示它的字段，改完点「更新所选」；「＋添加」「删除所选」增删；「↑上移」「↓下移」调整顺序。类型下拉可选：`单击 / 双击 / 长按 / 移动 / 滚轮 / 按键 / 输入数值 / 延时 / 归零 / 人工确认 / 自定义按钮`。把表单里「类型」选成对应项，勾选的那个字段才可用，其它会自动置灰。**「输入数值」**步骤里「表格列」是下拉（可再手动输列名或0-based列序号），还能填 `前置文本/后缀文本/空值兜底/小数位/输入后回车`。
4. **自定义按钮**：『编辑对象』下拉可切到「主流程」或某个按钮；「＋新建按钮」把一段步骤命名单成一个按钮。按钮既可被插入到流程（类型选 `自定义按钮`，填按钮名），也能在下方**「按钮快捷执行」区一键即时执行**（适合人工导航、翻页）。
5. **坐标定位（两种方式，二选一）**：
   - **方式一（推荐，F8 定位）**：顶部「坐标定位」区——先把工控机鼠标移到屏幕左上角，点 **●归零**建立原点；用 **▲▼◀▶** 方向键（步长可调）把光标挪到目标位置；在「步骤流程」里**选中一个鼠标类步骤**（单击/双击/长按/移动），按 **F8** 或点「F8 记录到所选步骤」，当前光标坐标就写进该步骤。
   - **方式二（旧校准）**：点「校准坐标」，逐个把光标移到每个步骤坐标——对准点『是』，没对准就输入 `+20,0`、`0,-10` 微调，校准完自动写回 config.json。
6. **开始填数**：点「▶ 开始填数」，会弹出「请把工控机鼠标移到屏幕左上角」的对话框，照做后点『是』；之后每填完一步/一行，界面亮起「✔ 已确认，继续下一行/下一步」按钮——去工控机屏幕核对无误后点它才继续。
7. **其他**：底部日志实时显示每一步动作；「Dry Run 预览」只打印指令不动工控机；「■ 停止」会立即中断并恢复操作——即使串口卡住（端口被占用/设备拔出），最长 12 秒后界面自动强制恢复，不会卡死。

> 命令行版 `python run.py` 功能相同，两者共用同一个 config.json，可混用。

### 7.2 命令行使用流程

1. 接好线（第 3 节），Pico 插工控机，CH340 插笔记本。
2. 笔记本上打开 PowerShell/CMD，进入本项目目录：
   ```powershell
   cd host
   copy config.example.json config.json   # 第一次执行
   notepad config.json                    # 按第 6 节改成你的串口号、表格路径
   python run.py
   ```
3. 脚本启动后会自动连串口 → 测 Pico 是否在线 → 读表格。
4. 如果 `start_home: true`：脚本提示「请把工控机的鼠标移到屏幕左上角，然后回车」。照做，回车。脚本会把光标原点对准左上角。
5. 脚本开始逐条填入：
   ```
   ── 第 1 行 ──
   [点击] 温度 输入 25.5
   [点击] 压力 输入 101.3
   [点击] 转速 输入 1500
   请到工控机上确认这一行的数值，确认无误后按回车继续…
   ── 第 2 行 ──
   ...
   ```
6. 每行填完你都去工控机小屏幕上看一眼，没问题就回笔记本按回车，填下一行。
7. 全部完成会写 `host/.progress` 断点文件并提示完成。**中途断电/中断也没关系**，下次运行问你是否从上次断点继续。

#### 命令行选项
```powershell
python run.py --config config.json          # 指定配置文件（默认 config.json）
python run.py --calibrate                    # 校准模式：逐个把光标移到每个坐标但不输入，人工回报是否对准
python run.py --dry-run                      # 只打印将要发送的指令序列，不连串口不发指令
python run.py --resume                        # 直接从断点继续（不询问）
```

## 8. 坐标校准（第一次必做）

1. 先把工控机软件打开、窗口放到它平时干活的位置（**固定位置，以后别动**）。
2. 运行 `python run.py --calibrate`。
3. 脚本提示把鼠标移到屏幕左上角，回车（原点校准）。
4. 脚本逐个把光标移到流程里**每个需要鼠标定位的步骤**（click/dblclick/move/press_at）的坐标，**停在目标位置**（只移动，不点击）。
5. 你看工控机屏幕：
   - 光标正好对准 → 按 `y`；
   - 偏了 → 按 `n`，脚本会请你输入微调的像素值，比如「右移 20 就输入 `+20,0`，下移 10 输入 `0,+10`」，脚本更新配置后重试。
6. 逐项校准完，配置就是你工控机屏幕上的真实坐标了，之后正常跑即可。

> 提示：不确定像素差值时，一次调 ±20 像素比较稳妥。屏幕上 1 厘米大约 40～60 像素（小屏 800×600 或 1024×768 常见）。

## 9. 笔记本 ↔ Pico 串口协议（简洁版）

每行一条 JSON（UTF-8，以 `\n` 结尾）。Pico 每执行完一条回一条 `{"ack":"ok"}`。

| 笔记本 → Pico | 含义 |
|---|---|
| `{"op":"ping"}` | 在线检测，回 `{"pong":true}` |
| `{"op":"home"}` | 把光标甩到屏幕左上角并设原点 (0,0) |
| `{"op":"move_to","x":120,"y":96}` | 光标移到绝对坐标（相对上次位置移动） |
| `{"op":"click_at","x":120,"y":96}` | 移动到该坐标并左键单击 |
| `{"op":"dblclick_at","x":120,"y":96}` | 移动到该坐标并双击 |
| `{"op":"press_at","x":120,"y":96,"ms":800}` | 移动到该坐标，按住左键 800ms 后松开（长按） |
| `{"op":"wheel","delta":-120}` | 滚动滚轮；delta>0 上滚 / <0 下滚 |
| `{"op":"get_pos"}` | 查询当前光标坐标，回 `{"ack":"ok","x":..,"y":..}`（坐标定位用） |
| `{"op":"type","text":"25.5"}` | 键盘输入文本（ASCII；`\t` 会被转成 Tab） |
| `{"op":"key","key":"enter"}` | 按一个键：enter/tab/esc/f5/backspace/ctrl+a 等 |
| `{"op":"sleep","ms":500}` | 停 500ms |

> 新增的 `dblclick_at`/`press_at`/`wheel`/`get_pos` 需要更新 Pico 固件（重拷 `pico/code.py`，见第 4.1 节）。
> 旧固件也能跑，只是这些动作会报「未知指令」。

## 10. 故障排查

| 现象 | 原因 / 解决 |
|---|---|
| 脚本报「找不到 COM 口」 | 串口号不对：设备管理器里确认 CH340 的 COM 号，改 config.json |
| 脚本报「Pico 无响应 (ping 超时)」 | TX/RX 接反了（对调）；波特率不一致；CH340 没插好 |
| 工控机没有任何反应 | Pico 的 Micro-USB 线是**充电线**（不能传数据），换一条；或 Pico 固件没烧好（CIRCUITPY 盘重拷 code.py） |
| 光标点不到正确位置 | 校准模式重新校准；运行中有人动过工控机鼠标导致偏移（重新归零左上角） |
| 点「停止」卡住不恢复 | 多为串口被占用/设备拔出卡住。已加保护：串口打开有 3 秒上限、延时可被停止打断、12 秒看门狗自动强制恢复界面；再不行把 COM 口重新插拔/换 COM 号 |
| 输进去的数值不对/多字 | 输入框里有旧值 → 输入步骤/目标加 `"pre_keys": ["ctrl+a"]` 先清空 |
| 想输入中文 | 不支持（USB 键盘协议限制），数值类需求一般用英文和数字 |
